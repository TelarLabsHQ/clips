How to use a green screen clip

These clips are animations on pure chroma green (#00B140). Put the clip above your own video or photo, then remove the green so only the animation is left. It’s called keying.

In CapCut

  1. Add your own video or photo to the timeline.
  2. Add the green screen clip with Overlay → Add overlay.
  3. Select it, tap Remove BG → Chroma key, pick the green with the color picker, and raise Intensity until the green is gone.
  4. Raise Shadow a little if you see a green edge.

In other editors

  • Canva: background removal for videos is available on some plans; otherwise use CapCut, which is free.
  • Premiere Pro: apply Ultra Key and pick the green.
  • DaVinci Resolve: use the 3D Keyer or Delta Keyer in the Color or Fusion page.

Tips

  • Key first, then move and resize the clip. Keying a resized clip can leave soft green edges.
  • Our step-by-step guide to green screens in CapCut has pictures for each step.
